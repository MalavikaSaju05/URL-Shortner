# URL Shortener

A modern full-stack URL shortener web application built using Flask, SQLite, HTML, CSS, Bootstrap, and JavaScript. The project features a premium Glassmorphism-inspired UI, reusable short-link generation, click tracking analytics, and a responsive dashboard for monitoring URL performance.

## Features

* Shorten long URLs instantly
* Reuse existing short links for duplicate URLs
* Real-time click tracking
* Analytics dashboard with most-used URLs
* Modern Glassmorphism UI design
* Copy-to-clipboard functionality
* Responsive mobile-friendly layout
* Dark premium theme
* Built with Flask and SQLite

## Tech Stack

* Backend: Python, Flask
* Database: SQLite, SQLAlchemy
* Frontend: HTML, CSS, Bootstrap, JavaScript
* Deployment: Render
* Version Control: Git & GitHub

## Use Cases

* Sharing clean shortened links
* Tracking link engagement
* Learning full-stack web development
* Understanding Flask routing and database integration
